# E-commerce Sales Analysis Report

This report is generated by running `py main.py`. It summarizes the supplied 100-row, 7-column sales dataset after validation and cleaning.

## What the program reports
- Number of valid records and date range
- Total revenue, average transaction value, highest transaction, and lowest transaction
- Revenue grouped by product and region
- Monthly revenue trend
- Data-driven observations identifying the highest-performing product, region, and month

- `../visualizations/sales_by_product.png`
- `../visualizations/monthly_sales_trend.png`
- `../visualizations/sales_by_region.png`

Run the program to populate this report with the current calculated values. The dataset is sample practice data, not verified commercial data.
