# Internship Tasks — Python (Weeks 1–4)

This repository contains the four weekly Python internship assignments, arranged in separate folders.

## Folder structure

- `Week-1-Python-Basics/` — Personal Introduction Program
- `Week-2-Grade-Calculator/` — Student Grade Calculator
- `Week-3-Sales-Data-Analysis/` — CSV analysis with pandas
- `Week-4-Complete-Data-Analysis/` — Data cleaning, analysis, visualizations, and written insights

## Requirements

- Python 3.10 or newer
- Install each week's dependencies from its `requirements.txt` when provided.

## Run a task

Open the required week folder in VS Code or a terminal, then run the command shown in that folder's README.

> Dataset note: the Week 3 and Week 4 CSV included here is a reproducible sample dataset prepared for these tasks. It is not represented as the exact original inline dataset from the earlier chat.
