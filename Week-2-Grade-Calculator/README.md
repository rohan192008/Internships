# Week 2 — Student Grade Calculator

## Objective
Accept a student's marks, validate that the value is between 0 and 100, calculate a grade, and display an encouraging message.

## Concepts
Functions, `if/elif/else`, input validation, type conversion, and a `while` loop.

## Grade scale
| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |

## Files
- `grade_calculator.py`
- `test_cases.txt`

## Run
```bash
py grade_calculator.py
```
