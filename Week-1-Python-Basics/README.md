# Week 1 — Python Basics: Personal Introduction

## Objective
Create a beginner-friendly program that asks the user for personal details and prints a formatted introduction.

## Concepts
Variables, `input()`, `print()`, strings, `.strip()`, and f-strings.

## Files
- `personal_intro.py` — program
- `requirements.txt` — no third-party packages
- `test_cases.txt` — manual tests

## Run
```bash
py personal_intro.py
```

Enter your name, age, city, course, and hobby when prompted.

## Example
```
Enter your name: Om
Enter your age: 21
Enter your city: Ahilyanagar
Enter your course: B.Sc Computer Science
Enter your hobby: Coding

--- My Introduction ---
My name is Om.
I am 21 years old.
I live in Ahilyanagar.
I am studying B.Sc Computer Science.
My hobby is Coding.
```
